Support

Something not working, or an idea? Here's what to try first, and where to ask.

Something not working, or an idea? Open an issue on GitHub. Please include what you did, what you expected, and the output of styr doctor.

First things to try

  • styr doctor checks every part (service, agent hooks, routing, Tailscale, pairing, notifications) and says what to fix.
  • A session doesn't show up on the phone: type /styr in it. Agents started before styr setup need a new terminal tab.
  • Messages from the phone aren't typed in, or approvals don't appear: start the agent again in a new tab (so it runs through Styrman), then /styr.
  • The phone can't reach the Mac: make sure Tailscale is on for both. On the iPhone, Tailscale's VPN On Demand keeps it connected.
  • Pair again: run styr pair on the Mac and scan the code with the phone's camera.
  • Codex asks to review hooks: choose “Trust all and continue” once; that lets Styrman follow the session.
